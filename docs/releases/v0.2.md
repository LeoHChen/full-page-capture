# Full Page Capture v0.2

Implements [feature request #1](https://github.com/LeoHChen/full-page-capture/issues/1): optional smart cleanup of advertisements, floating toolbars/images, and the regular site footer.

Enable **Clean page: ads, floating items & footer** in the popup. It is off by default. Both PNG and PDF use the cleaned capture; the preview reports removal counts. Ads and site footers are collapsed before capture dimensions are measured. Article/section footers, inline images, dialogs, and identifiable consent/access prompts are preserved. Original page styles and scroll position are restored after success or failure.

## Install or update

1. Download and unzip `full-page-capture-v0.2.zip`.
2. Open `chrome://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`. For an existing unpacked installation, replace that folder's files with the new ZIP contents and click **Reload**.
4. Open a webpage, invoke the extension, and enable the new cleanup option.

## Verification and limits

16 Node tests and a real headless Chrome screenshot test pass. The fixture removes 2 ad containers, 3 floating items, and 1 site footer, reducing height from 1,765 to 1,301 px. Pixel comparisons confirm inline images and article footers remain. Styles and scroll position are restored after a successful capture and an injected screenshot failure.

Detection is heuristic: unusual ads may remain and useful floating controls may be hidden. Turn cleanup off and recapture if needed. Cleanup does not inspect shadow DOM or iframe contents, block ad requests, or bypass access barriers. The browser test uses the real capture code through a CDP shim; installation and click-through in your Chrome profile remain manual.
