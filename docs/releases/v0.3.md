# Full Page Capture v0.3

Implements [feature request #2](https://github.com/LeoHChen/full-page-capture/issues/2): saved download-folder preferences.

PNG and PDF downloads now default to `screenshots/` inside Chrome's Downloads directory, normally `~/Downloads/screenshots`, without a save dialog. Open **Download settings** in the popup or preview to configure a different subfolder, use Downloads itself (empty folder), or enable **Ask where to save each file**. Preferences persist locally and apply to downloads from previews already open. Conflicting filenames are made unique.

Chrome only permits automatic downloads relative to its configured Downloads location. To save elsewhere, use the save dialog or change Chrome's Downloads location. The extension adds the `storage` permission to remember preferences.

## Install or update

Download and unzip `full-page-capture-v0.3.zip`. At `chrome://extensions`, enable Developer mode and load the extracted folder containing `manifest.json`. To update an unpacked installation, replace its files with the new ZIP contents and click **Reload**.
